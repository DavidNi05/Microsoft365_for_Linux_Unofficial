Settings & Preferences

Customize interface, left bar colors, synchronization behavior, and Linux integration.

1. Appearance & Interface (Visual & Fluent Design)

Control startup app, left bar palette, and sidebar responsiveness.
Left Bar Color Theme Choose whether the left sidebar uses default styling, matches the topbar color dynamically, or uses a custom color palette.
Default Startup App Select which Microsoft 365 application opens automatically on application launch.
Auto-Hide Sidebar Automatically collapse the sidebar while editing documents, revealing it when hovering over the left edge.
Compact Navigation Bar Compress the sidebar to ~54px showing icons only, saving horizontal screen real estate.

2. OneDrive & Cloud Synchronization

Tune native daemon polling intervals, logs, and metered connections.
Enable Native OneDrive Background Sync Allow the native abraunegg/onedrive daemon to run in the background, integrating your local home folder with Microsoft Cloud so you can edit files natively.
ℹ️ Note: Enabling this integrates your local home directory (~/OneDrive) directly with cloud storage.
Sync Polling Interval Frequency at which the daemon polls Microsoft Cloud for document changes.
Pause on Metered Connections Halt background document sync when connected to cellular 4G/5G hotspots or metered Wi-Fi networks.
OneDrive Sync Log Viewer Inspect real-time synchronisation activity, upload/download progress, and daemon states.

3. File Management & Cache

Directory locations, hardware acceleration, and session cleanup.
Custom Local OneDrive Folder Specify an alternate local directory for syncing files instead of the standard ~/OneDrive.
⚠️ Warning: Changing this folder from the default path prevents the native background daemon from reading locally tracked files until a full resync is executed.
Hardware Acceleration (GPU) Utilize GPU DRI hardware rendering. Keep disabled if experiencing graphical glitches or blank screens.
Clear Web Cache & Session Cookies Purge local temporary web storage, offline caches, and reset all preferences to default.

4. System Integration & Global Hotkeys

Startup behavior, desktop entry shortcuts, and hotkeys.
Desktop Shortcut Automatically create or remove a launch icon on your Linux desktop (~/Desktop or Área de trabalho) compliant with Flathub policies.
Launch at System Startup Start Microsoft 365 automatically upon Linux user session login.
Close to System Tray Closing the application window keeps it minimized in the system tray instead of exiting.
Global Quick-Launch Hotkey Bring Microsoft 365 to the foreground from anywhere in your desktop session. Requires X11 session or Desktop Portal GlobalShortcuts support.
