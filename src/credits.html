Microsoft 365 for Linux (Unofficial)

An open-source desktop client built for native Linux integration

Project Details

This application is a community-driven project providing seamless integration of the Microsoft 365 web ecosystem on Linux desktops. Built using Electron, Flatpak sandboxing, Fluent Design principles, and abraunegg/onedrive for native background file synchronization.
